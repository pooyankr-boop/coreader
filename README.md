# کُدِخوان — coreader

کتابخانه و خوانشگر نسخه‌های خطی و چاپی، به‌صورت کاملاً استاتیک. بدون سرور پایگاه‌داده، بدون کلید API، بدون وابستگی. همه چیز در مرورگر خواننده اجرا می‌شود و سرورِ همراهِ پروژه فقط برای خواندن فایل‌ها و دور زدن محدودیت‌های CORS در تصاویر IIIF است.

بخش‌ها:

- **راه** — کتاب‌های متنی، خوانش با حاشیه، هایلایت، جستجو و خوانش خودکار.
- **بیراه** — مجموعه‌های تصویری (حکاکی، نقاشی، نسخه‌های خطی) با نمایش IIIF و موزهٔ آثار.

## اجرا

```bash
node src/build/serve.js          # http://localhost:8081
PORT=3000 node src/build/serve.js
```

نیازی به ساخت پروژه نیست. فایل‌ها همان‌هایی‌اند که در مخزن‌اند.

## ساختار

```
index.html            کاتالوگ (راه و بیراه)
catalog/              جست‌وجو، تم، کارت‌های کتاب
reader/               خوانشگر متنی
viewer/               نمایشگر تصویر IIIF + تور درون‌سویی
tour/                 تور متنی (زیرزمین)
books/                کتاب‌ها: کتاب.json + متن/تصاویر + مانیفست IIIF
books-index.json      ایندکس همه کتاب‌ها برای کاتالوگ
assets/               خوانشگر، واژه‌نامه، ترجمه، فونت‌ها
src/build/serve.js    سرور محلی + پراکسی مانیفست IIIF
docs/bierah/          آزمون‌ها (بخشی از سایت منتشرشده نیست)
```

## امکانات

**خوانش متنی** — اندازه و فونت و پهنای ستون و فاصلهٔ سطرها، دو حالت چیدمان، ذره‌بین، پاورقی و حاشیه‌نویسی، هایلایت با رنگ و شفافیت دلخواه، علاقه‌مندی و یادداشت، جستجو در متن، به‌خاطر سپردنِ محل خواندن.

**خوانش خودکار و خط‌بر** — تبدیل متن به گفتار با موتور مرورگر، و تشخیص گفتار برای پیگیری محل خواندن با صدا؛ با هر دو، کلیک روی واژه خوانش را به همان‌جا می‌برد.

**ترجمه** — لایهٔ ترجمهٔ سطرزیرسطر: هر سطر از متن، یک‌جا و ادبی ترجمه می‌شود و ترجمه دقیقاً زیر همان سطر می‌نشیند. فونت از جعبهٔ متن ارث می‌برد، رنگ و شفافیت تنظیم‌پذیر است، و با «جدا کردن» کل لایه به پنلی شناور تبدیل می‌شود که جابه‌جا می‌شود. مترجم‌ها:

| مترجم | توضیح |
|---|---|
| **گوگل** (پیش‌فرض) | بهترین کیفیت میان موتورهای رایگان و بدون کلید |
| **MyMemory** | حافظهٔ ترجمهٔ ماشینی؛ موتوری مستقل با پوشش اصطلاحات قدیمی |
| **خودکار** | گوگل، و در صورت خطا MyMemory |

**واژه‌نامه** — با راست‌کلیک روی واژه، معنی‌ها **همان‌جا و زیر همان مدخل** نمایش داده می‌شوند، نه فقط پیوند به بیرون. منابع:

- ویکی‌واژهٔ فارسی (`fa.wiktionary.org`) — معانی فارسی، دسته‌بندی‌شده بر اساس نوع واژه
- ویکی‌واژهٔ انگلیسی (`en.wiktionary.org`) — برای واژه‌های هر زبانی، و معانی‌اش خودکار به فارسی ترجمه می‌شود

هر دو API رسمی ویکی‌مدیا هستند، با CORS باز و بدون کلید. پیوندهای واژه‌نامه‌های بیرونی (واژه‌یاب، دهخدا، معین، عمید، گنجور) هم پایینِ همان منو می‌مانند.

**موزهٔ بیراه** — مجموعه‌های کامل آثار از منابع IIIF معتبر: ویکی‌انبار و آرشیو اینترنت. هر مجموعه مانیفست IIIF v2 محلی دارد و در نمایشگر، میرادور، یونیورسال ویور و TIFY هم باز می‌شود.

**نمایشگر تصویر** — بزرگ‌نمایی، چرخش، تنظیم نور و رنگ و کنتراست، ذره‌بین، مقابلهٔ متن و تصویر، ابزارهای ترسیم و لیزر برای ارائه، جستجو در متن، پنل اطلاعات و حاشیه.

**کلی** — تم تاریک/شب، ذخیرهٔ محلی کتاب‌ها و ویرایش‌ها در مرورگر، خروجی PDF از حاشیه‌ها، و پشتیبان‌گیری و بازیابی داده‌ها.

## آزمون‌ها

آزمون‌ها خودکنترلیِ بدون قاب‌کاری هستند و با Chrome بی‌سرخود و CDP اجرا می‌شوند. پوشهٔ `docs/` نه در سایت منتشرشده جایی دارد و نه در مخزن، پس این فرمان‌ها را فقط روی یک نسخهٔ کاری اجرا کن.

```bash
node src/build/serve.js &                     # سرور باید بالا باشد
node docs/bierah/_check_syntax.js             # صحت نحوی همه اسکریپت‌ها
node docs/bierah/_check_lexicon.js            # واژه‌نامه و پاک‌سازی هایلایت‌ها
node docs/bierah/_check_translate.js          # لایهٔ ترجمه
node docs/bierah/_check_panels.js             # نوار ابزار و حذف صدا
node docs/bierah/_check_museum.js             # مجموعه‌های IIIF
```

## استقرار

سایت به‌صورت خودکار از شاخهٔ `main` و از ریشهٔ مخزن روی GitHub Pages منتشر می‌شود؛ کافی است تغییرات روی `main` برود.

```bash
git add -A
git commit -m "توضیح تغییر"
git push origin main
```

## نکته‌ها

- هیچ کلید API در کد یا مرورگر وجود ندارد؛ مترجم‌ها و واژه‌نامه سرویس‌های عمومی رایگان‌اند و در صورت در دسترس نبودن، کتاب بدون آن‌ها هم خوانده می‌شود.
- داده‌های خواننده (پیشرفت خواندن، هایلایت‌ها، علاقه‌مندی‌ها، کتاب‌های محلی) فقط در `localStorage` همان مرورگر می‌ماند.
- فایل‌های موقت و آزمون‌ها در `docs/` نگهداری می‌شوند و جزئی از سایت منتشرشده نیستند.
