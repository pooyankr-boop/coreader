# coreader

سامانهٔ ساخت سایت استاتیک برای متون کهن و کلاسیک فارسی — ساختاردهی خودکار، حاشیه‌نویسی
مناسب دانشجوی ادبیات، جست‌وجو، و «خط‌بَر» (ردیابی صوتی هم‌زمان با خواندن).

## معماری

```
coreader/
  src/build/     — خط لولهٔ ساخت (Node.js، بدون وابستگی به بک‌اند در زمان اجرا)
    structure.js   — تبدیل متن خام به صفحه‌بندی + تشخیص فصل‌ها
    annotate.js    — حاشیه‌نویسی از واژه‌نامهٔ دستی + تشخیص واژگان نادر برای بازبینی
    search-index.js— ایندکس جست‌وجوی سبک (بدون کتابخانهٔ خارجی)
    render.js      — تجمیع books/*/book.json در خروجی site/ نهایی
    cli.js         — دستور ساخت: `coreader book` و `coreader site`
    serve.js       — سرور محلی سبک برای پیش‌نمایش site/
  src/reader/    — برنامهٔ کتابخوان مشترک بین همهٔ کتاب‌ها (HTML+CSS+JS ساده، بدون فریم‌ورک)
  src/ocr/       — OCR برای متونی که نسخهٔ متنی ندارند (فقط PDF/اسکن دارند)
    ocr_pdf.py     — PDF → تصویر صفحه → OCR اولیه (Tesseract + بستهٔ زبان فارسی)
    review.html    — ویرایشگر تصویر/متن کنار هم برای اصلاح خروجی OCR
  books/<slug>/  — دادهٔ منبع هر کتاب (book.json، candidates.json، source.pdf)
  site/          — خروجی نهاییِ استاتیک، آمادهٔ انتشار (مثلاً با GitHub Pages)
```

## افزودن یک کتاب جدید

### الف) اگر متن دیجیتال دارید

```
node src/build/cli.js book --input <مسیر فایل txt یا پوشهٔ page_NNN.txt> \
  --slug <شناسهٔ-کوتاه-لاتین> --title "<عنوان کتاب>" --author "<نویسنده>" \
  --pdf <مسیر PDF (اختیاری، برای نمایش کنار متن)>
```

این دستور:
1. متن را به صفحه و فصل تقسیم می‌کند (تشخیص خودکار «باب/فصل/...»، یا صفحه‌بندی مجازی اگر متن پیوسته باشد)
2. واژه‌نامهٔ دستیِ اصطلاحات کلاسیک را روی متن اعمال می‌کند
3. فهرستی از واژگان نادرِ همین کتاب برای بازبینی می‌سازد: `books/<slug>/candidates.json`

### ب) اگر فقط PDF/اسکن دارید (بدون متن دیجیتال)

```
python src/ocr/ocr_pdf.py <مسیر PDF> <پوشهٔ خروجی>
```

سپس `src/ocr/review.html` را از طریق یک سرور محلی باز کنید (نه file://؛ مثلاً
`python -m http.server` را در پوشهٔ src/ocr اجرا کنید)، پوشهٔ خروجی OCR را
انتخاب کنید، و متن هر صفحه را کنار تصویرش اصلاح کنید. سپس همان پوشه به‌عنوان
`--input` به مرحلهٔ (الف) داده می‌شود.

**دقت OCR فارسیِ کلاسیک را دست‌کم نگیرید** — تشخیص گفتار/نویسهٔ عمومی برای
واژگان کهن و عربی‌تبار خطای واقعی می‌دهد؛ ابزار review.html دقیقاً برای همین
اصلاح لازم است، نه یک قدم اختیاری.

### بازبینی واژگان نادر (candidates.json)

هر ورودی یک `term`، تعداد تکرار، و `gloss: null` دارد. برای افزودن معنی،
مقدار `gloss` را پر کنید (و در صورت نیاز `cat` را از میان
`arabic/poem/quran/hist/word/person/event` انتخاب کنید). بازسازی بعدی کتاب
(دستور `book` را دوباره اجرا کنید) این معانی را در `book.json` ادغام می‌کند
بدون آنکه به لیست کاندیدها دست بزند.

### ساخت سایت نهایی

```
node src/build/cli.js site
node src/build/serve.js   # پیش‌نمایش محلی روی http://localhost:8080
```

پوشهٔ `site/` نتیجهٔ نهایی است — می‌توانید مستقیماً آن را (مثلاً با GitHub
Pages، یا هر میزبان استاتیک دیگر) منتشر کنید.

## امکانات کتابخوان

- فهرست مطالب + جست‌وجوی متن (سبک، بدون کتابخانه)
- حاشیه‌نویسی دسته‌بندی‌شده (عربی/شعر/آیه‌وحدیث/تاریخ/لغت‌کهن/شخصیت/واقعه) با راهنمای شناور
- راست‌کلیک روی متن: افزودن/ویرایش/حذف حاشیه، ویرایش مستقیم متن، ابزار اعراب‌گذاری
- جست‌وجوی واژه در فرهنگ‌های معتبر (واژه‌یاب، دهخدا، معین، عمید، ویکی‌واژه، گنجور) —
  به‌صورت پیوند مستقیم، نه استخراج/بازتولید محتوای آن سایت‌ها (نسخهٔ قبلی این
  کار را با استخراج HTML خام از طریق پراکسی انجام می‌داد که محتوای غلط/نامرتب
  نشان می‌داد؛ این نسخه فقط پیوند می‌دهد)
- پنل PDF کنار متن (نه رویهٔ تمام‌صفحه)، دقیقاً منطبق با صفحهٔ در حال خواندن
- تنظیمات: فونت، اندازهٔ قلم، فاصلهٔ خطوط، ۶ پوستهٔ رنگی
- ذخیرهٔ محلیِ ویرایش‌های کاربر (localStorage، بدون بک‌اند)

### خط‌بَر (ردیابی هم‌زمان با خواندن با صدا)

موتور تطبیقِ اعتبارسنجی‌شده با دادهٔ واقعیِ ضبط‌شده (نه صرفاً نظری):

- نرمال‌سازی آوایی برای املای کهن (تشخیص گفتار مرورگر با گویش معیار امروزی کار می‌کند)
- تراز محلی به سبک Smith-Waterman به‌جای تطبیق کلمه‌به‌کلمه — امکان رد شدن از
  کلمات ناشنیده/غلط‌شنیده بدون گم‌کردن موقعیت
- کم‌کردن وزن کلمات پرتکرار و بی‌بار («و»، «را»، «که»...) — از جهش‌های غلط
  و دور روی متن جلوگیری می‌کند
- شکستن کلمات نیم‌فاصله‌دار (بی‌قياس، مالك‌الملكى) به توکن‌های جدا برای تطبیق بهتر
- دو حالت: «زنده» (در حین شنیدن، پنجرهٔ کوچک) و «نهایی» (بعد از تأیید، پنجرهٔ
  وسیع‌تر و محتاط‌تر) — پارامترها روی جلسات واقعیِ ضبط‌شده تنظیم شده‌اند
- ثبت جلسه (لاگ JSON + فایل صوتی) برای تنظیم دقیق‌تر در آینده

## توسعه‌های آینده (شناخته‌شده، انجام‌نشده)

- تشخیص خودکار فصل‌ها برای متونی که از الگوهای متفاوتی برای عنوان‌بندی استفاده
  می‌کنند (فعلاً فقط باب/فصل/مقاله/... را می‌شناسد)
- کیفیت OCR برای چاپ‌های کم‌کیفیت یا خط نستعلیق هم‌چنان نیازمند بازبینی دستی
  زیاد است — این ابزار OCR را «سریع‌تر» می‌کند، نه «بی‌نیاز از بازبینی»
- بیشتر ۲۵۰ کاندیدِ واژهٔ نادرِ کتاب اول (سمط العلی) هنوز بازبینی نشده‌اند
  (۳۴ مورد به‌عنوان نمونه بازبینی و اضافه شده است)
