نشست استودیوی صوت

۱. فایل‌ها

عکس صفحه (JPG، PNG) یا PDF. هر صفحهٔ PDF جداگانه خوانده می‌شود.

۲. زبان متن

می‌توانید چند زبان را ترکیب کنید. داده‌های هر زبان در اولین اجرا دانلود می‌شوند.

۳. ابزارهای OCR

ابزارکجا اجرا می‌شودبرای فارسی و نستعلیقوضعیت
Tesseract (این صفحه)مرورگر شما، رایگانخوب برای چاپی، ضعیف‌تر برای دست‌نویس و نسخ خطیفعال
Google Cloud Visionابریدقت بالاتر روی متن چاپی و عکسنیاز به کلید API و هزینه؛ بعد از تنظیم کلید
Azure AI Visionابریدقت خوب، پشتیبانی از چند زباننیاز به کلید API و هزینه؛ بعد از تنظیم کلید
Kraken / Calamariسرور اختصاصیبهترین گزینه برای نسخ خطی و خط تحریرینیاز به سرور؛ مرحلهٔ بعد

برای نسخ خطی، ابزار ابری یا سرور اختصاصی دقت بهتری دارد. فعلاً Tesseract تنها موتور فعال است.
