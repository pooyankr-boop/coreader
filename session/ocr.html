OCR — متن از عکس، PDF و مانیفست IIIF

نشست استودیوی صوت

۱. موتور OCR

Tesseract روی چاپی خوب است و برای دست‌نویس ضعیف است. Google و Azure دقت بالاتری دارند ولی کلید API لازم دارند و هزینه می‌برند (کلید روی سرور تنظیم می‌شود).

۲. زبان متن

در Tesseract می‌توانید چند زبان را ترکیب کنید. در موتورهای ابری، زبان اول انتخابی به‌عنوان زبان اصلی استفاده می‌شود.

۳. ورودی مانیفست IIIF

اگر متن از قبل داخل مانیفست باشد (annotation متنی)، همان استفاده می‌شود. وگرنه تصویر هر صفحه خوانده می‌شود.

۴. فایل‌های محلی

عکس صفحه (JPG، PNG) یا PDF. هر صفحهٔ PDF جداگانه خوانده می‌شود.

۵. نتیجه (قابل ویرایش)

هنوز متنی استخراج نشده است.
